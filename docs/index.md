# Welcome

![Checkerboard fMRI Task icon](assets/images/checkerboard_icon.png){ width="96" }

The Checkerboard fMRI Task shows a flickering black-and-white checkerboard on the
scanner screen. It is a standard visual stimulus: it switches on and off in blocks, and a
dot in the middle gives the participant something to look at. The scanner starts it
automatically, so the timing lines up with the scan.

It is a normal Windows program. The scanner PC doesn't need Python or anything else
installed.

## Download

[Download for Windows](https://github.com/stefandup/checkerboard_fmri_task/releases/latest){ .md-button .md-button--primary }

This button always opens the newest version. On that page, under **Assets**, click the
file named `CheckerboardFmriTaskSetup-v….exe`. Then double-click the downloaded file.
